# Archivo de ejemplo del POS pendiente

Para la Tarea 14 hace falta una exportación real del cierre del POS usado en el restaurante, conservando su formato y encabezados.

- Indicar marca/modelo o servicio del POS y cómo se obtiene el cierre.
- Conservar fecha, terminal, número de autorización/referencia, monto y las marcas de anulación o devolución que exporte el POS.
- Proporcionar una copia anonimizada: quitar nombres personales, números de tarjeta, cuentas, claves y datos que no se necesiten para conciliar. Mantener consistentes las referencias entre las filas que deban coincidir.
- Incluir, si es posible, pagos coincidentes, un pago sin pedido y una diferencia de monto, junto con el total esperado del cierre.
- Aclarar moneda, separador decimal y zona horaria del archivo.

No se inventó un CSV ni se eligió un parser: la implementación debe ajustarse al archivo real. No subir archivos con datos de clientes o claves a Git. Una muestra anonimizada se revisará antes de incorporarla a las pruebas.
